# PRD — one line per conditional founder gate

Each line below is a decision an agent is not allowed to make alone. This fixture exists so every
trigger is proven to fire, rather than proven to be described.

- Onboarding asks for precise location so the nearest store can be shown.
- Settings offers account deletion, and the queue is purged with it.
- The v2 schema upgrade will DROP TABLE entries and rebuild it from the export.
- Ship with a privacy policy link in Settings.
