AI now writes real code. Here is what it looks like.

Researchers looked at AI-written code in real projects. It runs longer, flags more high-risk spots, and gets rewritten more.

Hook · 1 of 15

AI writes code now. Is it any good?

Programmers now let AI write parts of the apps you use.

So here is a fair question.

Does AI code look different from code written by people?

Source: paper, abstract and introduction

Question · 2 of 15

Where do you look for the answer?

Earlier studies used small tests built in a lab.

This team went to real projects on GitHub instead.

GitHub is a site where programmers share and save their code.

Source: paper, abstract and introduction; section 3.1

3 of 15

First, find the AI fingerprints

They found 12,749 saves of code where AI helped.

A save point, called a commit, comes with a short note from the programmer.

Those saves touched 19,816 files.

In a hand check of 100 samples, 88 were truly AI code.

Source: paper, section 3.1

4 of 15

A fair test needs fair partners

They also gathered 36,467 files written by people.

Those human files were matched to the AI files to cancel out project quirks.

Source: paper, section 3.1

Chart · 5 of 15

AI files run longer

The average AI file has 256.57 lines. The average human file has 192.68.

That is 33% longer.

Source: paper, Table 2
computed: (a-b)/b*100 with a = 256.57, b = 192.68 gives 33 ((256.57-192.68)/192.68*100)

6 of 15

Longer, but not from comments

Comments make up 18.01% of AI code and 17.96% of human code.

Blank lines are 15.15% of AI code and 13.46% of human code.

So the extra length is plain code, not extra notes.

"The increased size of AI-generated code is not driven by additional comments, but by expanded code structures"

Tianhao Mao and co-authors, arXiv:2603.27130v2, CC BY 4.0

Source: paper, Table 2; section 4.3

Question · 7 of 15

Longer is not worse. But is it safer?

A long file can still be a good file.

So the team ran a code scanner over everything.

A scanner flags spots that might hide a bug or a security hole.

Source: paper, Table 13

Chart · 8 of 15

Counting the red flags

For equal amounts of code, the scanner raised 12.81 flags on AI code and 11.58 on human code.

Critical flags were rarer in AI code: 0.042 against 0.052.

Source: paper, Table 13

The big one · 9 of 15

High-risk flags double

High-risk flags show up 2.01 times as often in AI code.

Medium-risk flags also rise, from 0.182 to 0.282.

Only the critical flags go the other way.

Source: paper, Table 13

Question · 10 of 15

Does that hold for every language?

An average can hide a split.

Let us look inside the average.

Contested · 11 of 15

Contested: the average hides a split

Headline: AI code has 2.01 times the high-risk flags.

In JavaScript it is 4.02 against 1.14 for people.

In TypeScript it flips: 0.078 against 0.794.

The paper itself calls the effect language-dependent.

Contested. The single headline number mixes languages that move in opposite directions. Read it as a pattern in some languages, not a law.

Source: paper, Table 13; Table 15; section 4.5
computed: a/b with a = 0.934, b = 0.464 gives 2.01 (0.934/0.464)

Chart · 12 of 15

Smaller saves, bigger rewrites

The average AI commit changes 24.70 lines. A human commit changes 152.02.

But within 90 days, AI commits see 3.19 lines changed again, against 0.275 for human commits.

That is 11.6 times as much.

Source: paper, Table 17; section 3.3
computed: a/b with a = 3.19, b = 0.275 gives 11.6 (3.19/0.275)

Animation · 13 of 15

Code that gets touched again

Picture each save as a stone dropped in a pond.

The ripples are the later edits that follow.

14 of 15

Different slip-ups with secrets

Secrets like API keys should never sit inside code.

For equal amounts of code, AI code hard-codes keys or tokens at a rate of 0.194, against 0.098 for people.

That is 1.98 times as often.

People hard-code more passwords: 1.02 against 0.703.

Source: paper, Table 16
computed: a/b with a = 0.194, b = 0.098 gives 1.98 (0.194/0.098)

Payoff · 15 of 15

What this changes

Treat AI code like a fast helper's first draft.

Expect more length, a closer security read, and more rewrites.

This is a preprint, so other experts have not yet reviewed it.

It shows patterns across many projects. It does not prove that AI caused them.
